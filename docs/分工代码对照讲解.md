**讲解要点（答辩可讲的原话）**
- 扣款不是「先查余额再减」，而是 `update ... set balance = balance - #{amount} where user_id=? and balance >= #{amount}`，靠 `affected rows` 判断成功——**一条 SQL 完成校验+扣减**，天然抗并发送重复扣。
- 扣款成功但后续 `payOrder` 返回 0（订单已支付/已取消）时，`L222-229` 会**主动退款**并写 `fail` 流水，避免「钱扣了单没成」。
- 失败原因不是编的：`L198` 按真实余额拼 `余额不足（可用 ¥x，本单需 ¥y）`，后台支付流水页直接可见。
