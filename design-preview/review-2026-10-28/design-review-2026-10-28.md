# 前端视觉审查 · 2026-10-28

审查对象：`pet-web`（Vue 3 + Element Plus），商城 11 页 + 后台 27 个列表页。
方式：真实运行环境截图（Edge headless，1440×900 与 390×844，桌面/手机各一组）＋ 65 个样式文件的静态扫描 ＋ 关键色对对比度计算。
截图见同目录 `01`–`08`。本文为自查（没有独立评审者参与），交互状态、性能、无障碍行为标注为未验证。

> 这是当天第二轮全站复查。上一轮已修 6 项（订单表格溢出、移动端吸底购买栏、后台悬浮球默认右下、空态图标、看板配色统一、商品图重复）。本轮用新截图复核，只报**当前仍存在**的问题，并补上前一轮未覆盖的维度：对比度实测、图片归一化、状态与主行动优先级。

## 一、方向判断

**商城站有明确方向，并且落地了。** 松林绿 + 暖灰、不用卡片、只靠 1px 线与留白分层，首屏「在重庆，遇见值得托付的第一只伙伴」加手绘下划线，是编辑式（editorial）的做法，看得出意图，不是模板拼装。评测视角的完成度约 **8/10**。

**后台不是同一套设计。** 同一个项目里并存三种语言：

| 位置 | 语言 | 与 token 的关系 |
| --- | --- | --- |
| 商城全部页面 | 扁平排版（`flat.scss`，圆角 ≤8px，无投影，1px 线分层） | 严格遵守 |
| 后台列表页（订单、客户…） | `ui-stats` + `el-table`，扁平为主 | 基本合规 |
| 后台看板 `views/dashboard` | 卡片、圆角 9–20px、hover 上浮 2px + 投影、六色竖条 | 基本不合规 |
| 后台登录页 | 18px 圆角卡 + 三个模糊色团 + 大投影 | 不合规 |

后台**设计语言一致性 5/10**（功能密度和可用性本身没问题，问题在"像另一个产品"），全局一致性约 **4/10**。原因不是"丑"，是**同一件事有两种画法**：KPI 在订单页是竖线分栏（`ui-stats`），在数据看板是六张带左侧彩条的卡片。

## 二、三个最有影响的问题

### P1｜商品图片没有归一化，直接决定"值得托付"能不能被看见

位置：首页「本周值得一看」、在售宠物网格、宠物详情主图。

截图里同一行卡片：`三色柯基` 的主体只占画面约 25%，`纯白博美` 的特写占满 90%；背景分别是纯白棚拍、深蓝布景、草地、圣诞红毯；色温从偏黄到偏冷。首屏三图拼贴更明显——主图是"猫 + 黄毛巾 + 黑背景"，右上是深色背景的博美，右下是带粉色蝴蝶结的兔子，三张互相抢。

影响：卡片不看文字就能认出是用户上传的原始照片；2,500 元的猫和 800 元的兔子在视觉上没有建立任何等级差。这是全站唯一一处"再好的排版也救不回来"的地方。

调整建议：
1. 卡片图统一裁切规则：主体居中、主体高度占画面 65–75%；对主体过小的图用 `object-position` 单独校正，或统一去背 + 品牌浅底。
2. 首屏拼贴只放同一类背景（棚拍归棚拍），宁可从 3 张降到 2 张。
3. 上架图片验收三条：主体占位达标、背景简洁、色温中性。

### P2｜后台的可读性与语义，比它的外观问题更严重

位置：`layouts/admin/index.vue` 侧栏、`views/dashboard/index.vue`、`views/admin/login/index.vue`。

**(a) 侧栏激活项是全站最难读的一行字。** 激活底色 `#3a3a4a`，激活文字 `var(--brand-500)`，实测对比度 **2.13:1**（正文 8.50:1）。用户当前所在页面的名字，恰恰最看不清。

**(b) KPI 的涨跌颜色自相矛盾。** `dashboard/index.vue` 里：

```
&.up   { color: #d4380d; background: var(--brand-50); }  // 红字 + 绿底
&.down { color: var(--success-500); background: #f0f9eb; } // 绿字 + 绿底
```

结果：营业额 ↓28.7% 显示绿色（像好消息），`取消率` 没有 growth 字段只能显示"区间"——最需要盯的指标反而没有趋势；`互动量` 的徽标用的是"收藏"的增长率，与它的值（收藏+评论+点赞）不是同一个口径。另外 11px 的徽标对比度 4.38:1，未达 4.5:1。

**(c) 登录页是通用 AI 模板长相。** 18px 圆角卡、三个 60px 模糊色团、`0 18px 50px` 投影；logo 是粉绿渐变方块里的"宠"字，与商城的"绿方块 + 白色爪印 + CHONGWU HOME · 重庆"不是同一个品牌，后台侧栏又变成第三个（白字"宠"）。

调整建议：侧栏改深绿家族（`--brand-900` 底 + `--brand-300` 激活字，实测 5.63:1）；KPI 统一为 `ui-stats`；涨跌改成"对经营是好还是坏"（取消率也要有 delta），字色只表达好坏、箭头只表达方向；登录页去掉色团，用 `ui-panel` + 商城那枚爪印标。

### P3｜"不能买"比"能做什么"更抢眼

位置：`views/shop/pet/detail.vue:66-71`、`views/shop/home/PetCard.vue`。

已售宠物详情页的主行动区是四个等重按钮：`已被订走`（实心、禁用，视觉最重）→ `加入购物车`（禁用）→ `立即预约看宠` → `问 AI`。用户点进来第一眼看到的是"你不能买"，而唯一可做的两件事被压在同一排。商品网格里的 `已售` 卡也没有降权：图片不降饱和、价格照常显示、`已售` 只是一枚深色小标签，与其他卡完全同权。

调整建议：状态先于行动——标题旁一枚"已被订走"chip；主按钮换成"预约看同一品种"；禁用按钮降为一行说明文字；已售卡图片降饱和 12%、价格改中性灰。

## 三、规范层量化体检

| 项 | 结论 |
| --- | --- |
| 响应式断点 | 只 1 处越界：`views/admin/knowledge/index.vue` 用 900px（允许 480/768/1000/1240/1400） |
| 圆角 | 11 处超 8px 硬上限：dashboard 20/14/10/9、login 18/14×2、NotificationBell 10/14、admin/match 10 |
| 投影 | 29 处声明，其中真投影 9 处（AssistantDock、NotificationBell、login、dashboard、PetCard hover），其余是 `inset` 描边环或 token 引用 |
| 硬编码色值 | `element.scss` 44 处（EP 覆盖，可接受）、dashboard 22、AssistantDock 15、admin/login 13、PetSocial 8 |
| 字号 | 29 种取值，41 处不在九档内；含 `10px`（NotificationBell，低于自定 11px 下限）、11.5/13.5/15.5/19/25px 等半档 |
| 键盘焦点与动效偏好 | **复核更正**：`styles/index.scss` 已有全局 `:focus-visible` 与 `prefers-reduced-motion` 兜底，覆盖全站。首轮按"文件出现次数"统计得出"只有 2/65"，结论有误 |
| 图片替代文本 | 3 张后台缩略图缺 `alt`（comment / goods / like） |

对比度实测（WCAG AA 正文需 4.5:1）：

```
--text-3  #63716b 白底      5.12  ✓
--price   #a8542b 白底      5.29  ✓
--brand-600 #14614e 白底    7.37  ✓
--brand-700 #0f4e3f 白底    9.62  ✓
后台侧栏正文 #bfcbd9 / #2b2b36  8.50  ✓
后台侧栏激活 #1f7a63 / #3a3a4a  2.13  ✗
--text-4  #aeb8b3 白底      2.04  ✗  ← 看板 11px 副文 kpi-sub 用的就是它
看板 up 徽标 #d4380d / #eff6f3  4.38  ✗（11px）
```

`--text-4` 的 2.04:1 用在占位符里尚可，用在"今日 ¥0.00 · 客单价 ¥156.28"这种事实信息上就不可读。建议把它限定为禁用态，看板副文改用 `--text-3`。

## 四、页面级问题（按影响排序）

- **宠物粮页**：在售仅 2 款，`auto-fill` 网格从左排出两列，右侧留约 700px 空白，整页像没加载完。缺"商品少于 4 款"时的版式规则（建议少量时收窄容器或居中排）。
- **购物车**：只有 1 件商品时，结算条停在页面中段（视口 900、结算条约 y=505），其下约 400px 空白——页脚已整体移除，缺少收束元素，短内容页面会显得没做完。
- **详情页评价区**：5 星分布是 5 行 0 值长条 + 右侧孤零零的"0"，视觉上像渲染失败；点赞 / 评分 / 写评论 / 登录后评论四个入口挤在同一屏。
- **智能选宠**：问答面板高度固定，第 1 步内容只填了上半屏，下方留约 90px 空白；顶部三个数字标签"在售个体 / 维度 3 组 / 只上限 8"读起来像被截断的文案。
- **首页首屏媒体徽章**：`left: -18px` 是有意破格，落在两栏 64px 的间隙里，实测不压图片主体——**复核后撤回，非缺陷**。
- **助手挂球**：桌面默认 `position: fixed; top: 84px; right: 22px`，正好落在内容区（首屏压在拼贴图上，详情页压在信息栏旁）；手机端 56px 圆球压在底部标签栏上方，会盖住图片。可拖动能缓解，但默认位置就与内容冲突。
- **后台表格**：`el-table`（无斑马纹、行高 48）与 `ui-table`（斑马纹、行高 44）并存于同一后台。
